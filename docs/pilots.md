# Pilot and style gate

Pilot production requires the exact current plan approval. Studio selects one representative preview for every materially distinct configured style signature, rather than multiplying pilots by audience. The review subject binds plan version/hash, preview hashes and all pieces covered by that style.

An explicit approval or changes request is recorded against that exact subject. Changed previews create a new hash/version, so earlier approval cannot authorize batch production. An unchanged applicable style remains reusable for every covered piece.

Style approval does not verify product claims, mechanical media checks or independent QA.
